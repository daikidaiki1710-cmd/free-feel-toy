## B. 推奨サイトマップ

手戻り最小化のため、深い階層を作らず必要最小限のページ+ページ内セクション分割で構成する。LABは受注導線として重要なため他2ドメインよりやや厚めの内容にする。

```
/                … HOME(世界観+3ドメインへの入口+LAB訴求)
/lab             … LAB(Web/アプリ/AI/デザイン/事業支援 ※1ページ内でセクション分割)
/garage          … GARAGE(配送・引越し・荷上げ)
/living          … LIVING(暮らしのサポート)
/about           … Free Feel Toyについて(世界観・価値観・会社概要)
/contact         … お問い合わせ(分野選択式の1フォーム)
```

### 検討・決定事項
- `/lab` は Web/アプリ/AI/デザイン/事業支援を5ページに分割せず、**まずは1ページ内アンカーセクション構成**を採用(内容増加時に後から分割可能)
- `/about` は「会社概要」と「世界観・ブランドストーリー」を初期は1ページに統合。将来的に法人向け信頼性強化のため独立させる余地を残す
- EC・予約が無いため特定商取引法表記は必須ではないが、会社概要としての最低限の情報(商号・所在地・連絡先)は信頼性の観点で `/about` か `/contact` に必要 **【要確認: F-1参照】**

## C. HOMEセクション構成案

「世界観の没入 → 現実的な導線 → 信頼 → 行動」の順で設計する。

1. **ファーストビュー(秘密基地演出)** — ロゴ+「自由な発想。自由な想像。」をタイポグラフィ主体で表現。Motionで控えめだが印象的なアニメーション(重い動画は使わずCSS/Motion中心でLCPを守る)
2. **ブランドステートメント** — コンセプト文をスクロール演出付きで見せる、共感を作るセクション
3. **3ドメインへの入口(最重要導線セクション)** — GARAGE / LIVING / LAB を同格の3カードで明示。雰囲気より視認性・分かりやすさを優先し「迷わない」を担保する要
4. **LABピックアップ(今回の主役)** — Web / アプリ / AI / デザイン / 事業支援の強みを一段掘り下げ、受注導線を意識したセクション
5. **Free Feel Toyが大事にすること** — 人とのつながり/物を大切にする心/新しい挑戦/暮らしを楽しくするアイデアをカードやアイコンで表現
6. **信頼セクション** — 会社概要の抜粋・対応領域など。ここでトーンを黒基調からやや明るめへ緩め、GARAGE/LIVING目的の訪問者への安心材料にする
7. **お問い合わせCTA** — 「GARAGEの相談」「LIVINGの相談」「LAB(Web/アプリ)の相談」など分野別に入口を分けたCTAで意図の混乱を防ぐ
8. **フッター** — グローバルナビ・会社情報・SNS(あれば)

## D. LAB / GARAGE / LIVING の役割整理

| ドメイン | 役割 | トーン | 主目的 |
|---|---|---|---|
| GARAGE | 配送・引越し・荷上げなど実務的なモノを運ぶ事業 | 実務感・安心感を軸にしつつ、Free Feel Toyらしい「新しい始まりのワクワク」を要素として残す | 見積もり相談・依頼への転換 |
| LIVING | 暮らしのサポート | 最も配慮が必要な領域。黒×秘密基地感は抑えめにし、柔らかさ・読みやすさ・安心感を優先 | 相談・利用検討への転換 |
| LAB | Web・アプリ・AI・デザイン・事業支援 | 秘密基地の世界観が最もフィットする領域。スタイリッシュ・クリエイティブを全開に | 制作・支援の問い合わせ、将来の受注 |

3つは「同じ会社の3つの部屋」という位置づけとし、共通の世界観(ロゴ・タイポグラフィ・基本コンポーネント)を保ちつつ、配色の明度・写真/イラストの選び方・コピーの温度感でドメインごとの違いを出す(=デザインシステムは1つ、テーマトークンだけドメインで切り替える方針)。

## E. ユーザーが混乱しない導線案

- グローバルナビに常時 GARAGE / LIVING / LAB を明示し、今どの「部屋」を見ているか常にわかるようにする
- HOMEはスクロール1〜2枚目までに必ず3ドメイン入口を配置し、世界観演出だけで離脱させない
- 検索流入で `/living` や `/garage` に直接着地するケース(高齢者含む)を想定し、各ドメインページ単体でも安心して読める設計にする(Free Feel Toy全体のリンクは控えめに、圧を与えない)
- CTA文言はドメインごとに心理的ハードルを調整(例: GARAGE「見積もりを相談する」、LIVING「まずは相談する」、LAB「プロジェクトを相談する」)
- お問い合わせは1フォーム+分野選択(プルダウン/タブ)にまとめ、フォーム乱立による手戻りを避ける
- フッターに全ドメインへの導線を常設し、どのページからでも迷わず戻れるようにする
